O grimório não abriu

O Mesa Infinita usa módulos JavaScript, que o navegador bloqueia quando o arquivo é aberto direto do disco (file://).

Sirva a pasta por um servidor local — por exemplo, dentro da pasta do jogo:

npm start

ou publique no Cloudflare Pages. Depois abra http://localhost:4173.
